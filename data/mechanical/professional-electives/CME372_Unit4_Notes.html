CME372 — Unit IV: Finite Element Analysis

R-2021 • CAD and CAE • Exam-oriented notes

Syllabus: historical background, weighted residual methods, FEM concept, variational formulation, Ritz method, finite element modelling, element equations, linear/higher-order shape functions, bar and beam elements, heat-transfer applications.

1. Finite Element Method

FEM is a numerical method that divides a continuous engineering domain into a finite number of smaller elements connected at nodes. The unknown field variable is approximated using shape functions.

Basic FEM sequence: Idealise domain → mesh → select element/interpolation → derive element equations → assemble global equations → apply boundary conditions → solve → post-process.

2. Historical Background

Finite-element concepts developed from structural analysis, variational methods and numerical approximation. With digital computers, FEM became a general engineering analysis tool for structures, heat transfer, fluids and coupled problems.

3. Weighted Residual Methods

When an approximate solution does not exactly satisfy a governing differential equation, a residual remains. Weighted residual methods force the weighted integral of this residual to satisfy selected conditions.

∫Ω wR dΩ = 0

Different choices of weighting functions lead to methods such as Galerkin and related formulations.

4. Variational Formulation

A variational formulation converts a differential-equation problem into an equivalent stationary functional problem when an appropriate functional exists. It provides a powerful route to FEM equations.

5. Ritz Method

The Ritz method assumes an admissible approximate solution containing unknown coefficients and determines those coefficients by making the governing functional stationary.

δΠ = 0

In structural problems, Π may represent total potential energy.

6. Finite Element Modelling

  1. Define geometry and idealisations.
  2. Select element type.
  3. Generate mesh.
  4. Assign material properties.
  5. Define loads and boundary conditions.
  6. Form element equations.
  7. Assemble and solve.
  8. Interpret stresses, strains, displacements or temperatures.

7. Shape Functions

Shape functions interpolate the field variable inside an element from its nodal values.

u(x) ≈ N₁(x)u₁ + N₂(x)u₂ + … + Nₙ(x)uₙ

Linear elements use first-order interpolation. Higher-order elements add intermediate nodes and higher-order interpolation, which can improve representation of curved fields without necessarily using many elements.

8. Bar Element

A two-node axial bar element models one-dimensional axial deformation. Its stiffness depends on Young's modulus E, cross-sectional area A and element length L.

k = (EA/L) [1 −1; −1 1]

The matrix form is a compact representation; actual assembly places each element contribution into the global stiffness matrix.

9. Beam Element

A beam element models bending behaviour. Depending on formulation, nodal degrees of freedom can include transverse displacement and rotation. Beam stiffness depends on E, second moment of area I and element length.

10. Heat Transfer Application

FEM can solve steady or transient heat-conduction problems by converting the governing heat equation into element equations. Temperature becomes the primary unknown.

Thermal FEM: thermal domain → mesh → conductivity/material properties → thermal loads/boundary conditions → assemble → solve nodal temperatures → calculate heat flux.
