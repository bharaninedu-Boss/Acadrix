1. What is FEM?

The Finite Element Method (FEM) is a numerical method for solving engineering field problems by dividing a continuous domain into a finite number of smaller elements connected at nodes. The unknown field variable is approximated inside each element using interpolation or shape functions.

Typical FEM workflow: Problem definition → idealisation → discretisation/mesh → element selection → material properties → loads and boundary conditions → element equations → global assembly → solution → post-processing and verification.

2. Historical Background

Finite-element ideas developed from structural analysis, variational methods and numerical approximation. The availability of digital computers enabled large systems of element equations to be assembled and solved, making FEM practical for complex engineering geometries.

3. Why Discretisation is Needed

  • Real engineering domains are often geometrically complex.
  • Material properties or loads may vary over the domain.
  • Exact closed-form solutions may not be available.
  • Small elements permit a manageable approximate representation.

4. Weighted Residual Methods

Suppose an approximate solution does not satisfy the governing differential equation exactly. The difference is called the residual. Weighted residual methods select weighting functions and force the weighted residual to satisfy an integral condition.

∫Ω wR dΩ = 0

Galerkin idea

In the Galerkin approach, the weighting functions are selected from the same family as the approximation functions. The key exam point is the conversion of an unsatisfied differential equation into integral equations that determine the unknown approximation coefficients.

5. Variational Formulation

A variational formulation expresses a problem through a functional whose stationary value corresponds to the governing equations and boundary conditions, when an appropriate functional exists.

δΠ = 0

For a structural problem, Π can represent total potential energy. The stationary condition provides the basis for obtaining algebraic finite-element equations.

6. Ritz Method

The Ritz method assumes an admissible approximate field containing unknown coefficients. The coefficients are determined by making the functional stationary.

Ritz sequence: choose admissible approximation → substitute into functional → express functional in unknown coefficients → differentiate with respect to each coefficient → set derivatives to zero → solve simultaneous equations.

7. FEM Modelling Steps

  1. Define the physical problem and assumptions.
  2. Idealise geometry and physics.
  3. Discretise the domain into elements.
  4. Select suitable element type and interpolation.
  5. Define material properties.
  6. Apply loads and boundary conditions.
  7. Derive element equations.
  8. Assemble the global equations.
  9. Apply boundary conditions to the global system.
  10. Solve for nodal unknowns.
  11. Calculate derived quantities such as stress, strain, heat flux or reaction.
  12. Check mesh sensitivity and physical reasonableness.

8. Element Equations

Each element converts the governing field problem into an algebraic relation among nodal unknowns. For a structural problem, this commonly takes the form:

[k]e{u}e = {F}e

Element matrices are assembled according to connectivity to obtain the global system:

[K]{U} = {F}

9. Shape Functions

Shape functions interpolate the field variable inside an element from its nodal values.

u(x) = N₁(x)u₁ + N₂(x)u₂ + … + Nn(x)un

They are selected so that the approximation satisfies the required interpolation properties. For nodal interpolation, the shape function associated with a node is one at that node and zero at the other element nodes.

Linear vs higher-order elements

Linear elementHigher-order element
First-order interpolation.Second or higher-order interpolation.
Fewer nodes per element.More nodes/interpolation terms.
Simple and computationally efficient.Can represent curved fields/geometry more accurately per element.

10. Two-Node Bar Element

A two-node bar element models one-dimensional axial deformation. For a prismatic bar with constant E, A and length L:

[k] = (EA/L) [ 1 −1 ] [−1 1 ]

The nodal displacement vector contains the two axial displacements. The element stiffness relates nodal displacements to nodal forces.

Interpretation

  • E controls material stiffness.
  • A controls load-carrying area.
  • L appears in the denominator, so a longer element has lower axial stiffness for the same E and A.

11. Beam Element

A beam element models bending behaviour. Depending on the formulation, each node can have transverse displacement and rotation as degrees of freedom.

  • Young's modulus E affects stiffness.
  • Second moment of area I controls bending resistance.
  • Element length strongly affects stiffness.
  • Boundary conditions determine the beam's response.

12. Heat-Transfer Applications

FEM can be applied to steady and transient heat-conduction problems. Temperature is normally the primary unknown.

Thermal FEM sequence: thermal domain → mesh → thermal conductivity/material data → thermal boundary conditions and heat loads → element thermal equations → global assembly → nodal temperatures → heat-flux/post-processing.

13. Simple Bar Numerical

Given: E = 200 GPa, A = 400 mm², L = 1,000 mm.
Find: axial stiffness k of a two-node bar.
Step 1 — Convert: E = 200,000 N/mm².
Step 2 — Formula: k = EA/L.
Step 3 — Substitute: k = (200,000 × 400)/1,000.
Step 4 — Arithmetic: 200,000 × 400 = 80,000,000 N; 80,000,000/1,000 = 80,000 N/mm.
Final answer: k = 80,000 N/mm.
