1. FEM Concept

The Finite Element Method (FEM) is a numerical method for solving engineering field problems by dividing a continuous domain into smaller finite elements connected at nodes. The unknown field variable is approximated inside each element using interpolation or shape functions.

Typical workflow: Problem definition → idealisation → discretisation/mesh → element selection → material properties → loads and boundary conditions → element equations → global assembly → solution → post-processing and verification.

2. Historical Background

Finite-element ideas developed from structural analysis, variational methods and numerical approximation. Digital computing made it practical to assemble and solve large systems of element equations for complex engineering problems.

3. Weighted Residual Methods

If an approximate solution does not exactly satisfy the governing differential equation, the difference is called the residual. Weighted residual methods select weighting functions and impose an integral condition on that residual.

∫Ω wR dΩ = 0

In the Galerkin idea, weighting functions are selected from the same family as the approximation functions.

4. Variational Formulation

A variational formulation expresses the problem through a functional whose stationary value corresponds to the governing equations and boundary conditions when an appropriate functional exists.

δΠ = 0

For structural problems, Π can represent total potential energy.

5. Ritz Method

The Ritz method assumes an admissible approximate field containing unknown coefficients. The coefficients are obtained by making the selected functional stationary.

Sequence: choose admissible approximation → substitute into functional → express functional in unknown coefficients → differentiate with respect to each coefficient → set derivatives to zero → solve.

7. Element Equations

For a structural element, a typical algebraic relation is:

[k]e{u}e = {F}e

Assembly according to connectivity gives the global system:

[K]{U} = {F}

8. Shape Functions

Shape functions interpolate the field variable from nodal values:

u(x) = N₁(x)u₁ + N₂(x)u₂ + … + Nn(x)un

For nodal interpolation, the shape function associated with one node is one at that node and zero at the other element nodes.

Linear vs higher-order

  • Linear: first-order interpolation, fewer nodes and simpler computation.
  • Higher-order: higher-order interpolation with additional nodes/terms, allowing more flexible representation of curved fields.

9. Two-Node Bar Element

For a prismatic bar with constant E, A and length L:

[k] = (EA/L) [ 1 −1 ] [−1 1 ]

E controls material stiffness, A controls load-carrying area and L appears in the denominator.

10. Beam Element

A beam element represents bending. Depending on formulation, nodal degrees of freedom include transverse displacement and rotation. Bending stiffness depends on E and second moment of area I, together with element length.

11. Heat-Transfer Applications

FEM can be applied to steady and transient heat-conduction problems. Temperature is normally the primary unknown.

Thermal FEM: thermal domain → mesh → conductivity/material data → thermal boundary conditions/heat loads → element thermal equations → global assembly → nodal temperatures → heat-flux/post-processing.

12. Worked Numerical — Two-Node Bar Stiffness

Given: E = 200 GPa, A = 400 mm², L = 1,000 mm.
Convert: E = 200,000 N/mm².
Formula: k = EA/L.
Substitute: k = (200,000 × 400)/1,000.
Arithmetic: 200,000 × 400 = 80,000,000 N; 80,000,000/1,000 = 80,000 N/mm.
Final: k = 80,000 N/mm.
