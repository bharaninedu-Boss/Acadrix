Value Engineering Job Plan and Process

Exam-friendly notes covering the seven phases of the job plan, FAST diagramming, behavioural and organisational aspects, ten value-analysis principles and the benefits of Value Engineering.

1. Value Engineering Job Plan

The Value Engineering (VE) Job Plan is a systematic sequence used to study a product, service or project, identify its functions, generate alternatives and recommend improvements in value. A commonly taught seven-phase Mudge-style job plan is:

1. General Phase

Select and define the study, scope the problem, form the team and establish objectives.

2. Information Phase

Collect facts about requirements, design, performance, materials, processes, costs and constraints.

3. Function Phase

Identify and classify functions; relate functions to cost and worth and locate value-improvement opportunities.

4. Creation Phase

Generate alternative ways of performing the required functions without premature judgement.

5. Evaluation Phase

Screen alternatives for feasibility, performance, cost, reliability and other requirements.

6. Investigation Phase

Develop promising alternatives using technical, cost, supplier and implementation information.

7. Recommendation Phase

Prepare and present the best proposals, supporting data, expected benefits and implementation requirements.

The seven-phase sequence above is the standard job-plan form commonly taught for this syllabus; other VE organisations use different phase counts, so exam answers should follow the seven-phase form expected for CME338. citeturn0search25turn0search26

2. Purpose of the Job Plan

  • Provides a logical route from problem definition to recommendation.
  • Prevents the team from jumping directly to cost-cutting ideas.
  • Moves attention from parts to the functions that must be achieved.
  • Creates time for both creative idea generation and objective evaluation.
  • Provides a documented basis for selecting and implementing value-improvement proposals.

3. FAST Diagramming

FAST = Function Analysis System Technique

FAST is a function-oriented diagramming method used to arrange functions in logical relationships. It helps the VE team understand what a system must do rather than concentrating first on what the system looks like.

Basic logic

  • How? moves toward the functions that explain how the left-hand function is achieved.
  • Why? moves toward the higher-level purpose of the function.
  • The basic function is central to the purpose of the product or system.
  • Supporting functions help the basic function to be achieved.
Example: Store energy ← HOW? Convert energy ← HOW? Transfer energy   |   WHY? moves toward the required higher-level purpose.

Uses of FAST

  • Clarifies functions in a complex product or process.
  • Shows functional relationships and dependencies.
  • Helps identify unnecessary or weakly justified functions.
  • Provides a basis for creativity and alternative generation.
  • Supports function-cost and value analysis.

4. Behavioural and Organisational Aspects

Value Engineering is not only a technical exercise. It involves people, departments and decisions. Successful VE therefore requires a cooperative organisational environment.

AspectExam point
Multidisciplinary teamDifferent functions such as design, manufacturing, purchasing, quality and cost analysis contribute different viewpoints.
Management supportManagement should provide authority, time, resources and a clear objective for the study.
Team communicationFacts and ideas should be shared openly so that technical and commercial constraints are understood.
Resistance to changePeople may defend an existing design because of habit, ownership or fear of risk. VE should evaluate functions objectively.
Creative climateDuring idea generation, criticism should be controlled so that useful alternatives are not rejected too early.
Implementation attitudeA proposal creates value only when the organisation can approve, develop and implement it successfully.

5. Ten Principles of Value Analysis

For exam preparation, the following ten value-test questions are a commonly taught formulation associated with value-analysis practice:

  1. Does the item or feature contribute value?
  2. Is its cost proportionate to its usefulness?
  3. Does it need all of its features?
  4. Is there anything better for the intended use?
  5. Can a usable part be made by a lower-cost method?
  6. Can a standard product be found that will perform the required function?
  7. Is it made using proper tooling considering the quantity produced?
  8. Are the materials reasonable for the required function?
  9. Will another dependable supplier provide it for less?
  10. Is anyone buying it for less while obtaining the required performance?

These questions are widely reproduced as value tests in engineering/industrial-engineering teaching material. citeturn2search3turn2search5

6. Benefits of Value Engineering

  • Lower unnecessary cost: removes costs that do not contribute to required function or customer value.
  • Better function-to-cost relationship: encourages alternatives that provide required performance economically.
  • Improved quality and reliability: alternatives are evaluated against functional and performance requirements, not cost alone.
  • Improved teamwork: multidisciplinary participation combines design, manufacturing, purchasing and other viewpoints.
  • Better decision-making: decisions are supported by function, cost, worth and feasibility information.
  • Innovation: the creation phase encourages new materials, methods, processes and designs.
  • Customer benefit: required functions can be maintained or improved while avoiding unnecessary expenditure.
  • Systematic implementation: the Job Plan provides a structured route from study to recommendation.

7. Unit II — Exam Points

Remember the seven phases:
General → Information → Function → Creation → Evaluation → Investigation → Recommendation.

FAST: Function Analysis System Technique — a diagramming tool for arranging functions and their logical relationships.

Core idea: VE is not simply “cut cost”; it seeks the required function at better overall value.

8. Quick Revision

  • Job Plan: systematic sequence for conducting a VE study.
  • FAST: Function Analysis System Technique.
  • Function phase: identifies and analyses what the item must do.
  • Creation phase: generates alternatives.
  • Evaluation phase: screens alternatives.
  • Investigation phase: develops promising alternatives with supporting facts.
  • Recommendation phase: presents the selected proposal.
  • Behavioural key: teamwork + communication + openness to change.

Memory line: General → Information → Function → Create → Evaluate → Investigate → Recommend.
