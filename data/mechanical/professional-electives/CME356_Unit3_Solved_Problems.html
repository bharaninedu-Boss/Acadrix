Problem 1 — Maximum Shear Stress Under Biaxial Loading

Given: Principal stresses are σ1 = 180 MPa and σ2 = 60 MPa. Assume plane stress, so σ3 = 0.
Find: Maximum shear stress.
Formula:
τmax = σmax − σmin2
Substitute:
τmax = (180 − 0)/2 MPa
Arithmetic:
τmax = 180/2 = 90 MPa
Final answer: Maximum shear stress = 90 MPa.

Problem 2 — Von Mises Equivalent Stress

Given: σ1 = 160 MPa, σ2 = 80 MPa, σ3 = 0 MPa.
Formula:
σe = √[(σ1 − σ2)² + (σ2 − σ3)² + (σ3 − σ1)²] / 2
Substitute actual values:
σe = √[(160 − 80)² + (80 − 0)² + (0 − 160)²] / √2
Arithmetic:
= √[6400 + 6400 + 25600] / √2
= √38400 / √2
= √19200
≈ 138.56 MPa
Final answer: Von Mises equivalent stress ≈ 138.6 MPa.

Problem 3 — Goodman Fatigue Design Check

Given: Alternating stress σa = 90 MPa; mean stress σm = 60 MPa; endurance strength Se = 270 MPa; ultimate tensile strength Sut = 600 MPa.
Find: Goodman factor of safety.
Formula:
σaSe + σmSut = 1n
Substitute:
1/n = 90/270 + 60/600
Arithmetic:
90/270 = 0.3333
60/600 = 0.1000
1/n = 0.4333
Next formula:
n = 1/0.4333
Final arithmetic:
n ≈ 2.31
Final answer: Goodman factor of safety ≈ 2.31, under the stated simplified model.

Problem 4 — Cumulative Fatigue Damage

Given: A component experiences n1 = 20,000 cycles at a stress level where N1 = 100,000 cycles to failure, and n2 = 10,000 cycles where N2 = 50,000 cycles.
Formula:
D = n1N1 + n2N2
Substitute:
D = 20,000/100,000 + 10,000/50,000
Arithmetic:
D = 0.20 + 0.20 = 0.40
Final answer: Linear cumulative damage index D = 0.40. In the simplified linear-damage model, the value is below the nominal failure criterion D ≈ 1.

Problem 5 — Larson-Miller Parameter

Given: Absolute temperature T = 873 K, rupture time tr = 1000 h, and material constant C = 20.
Formula:
PLM = T(C + log10 tr)
Substitute:
PLM = 873[20 + log10(1000)]
Evaluate logarithm:
log10(1000) = 3
Next calculation:
PLM = 873(20 + 3)
= 873 × 23
Arithmetic:
PLM = 20,079 K
Final answer: Larson-Miller parameter = 20,079 K for the stated convention and data.

Problem 6 — Stress Concentration

Given: Nominal stress σnom = 80 MPa and maximum local stress σmax = 240 MPa.
Formula:
Kt = σmaxσnom
Substitute:
Kt = 240/80
Arithmetic:
Kt = 3
Final answer: Theoretical stress-concentration factor Kt = 3.0.
