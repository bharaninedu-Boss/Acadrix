Value Engineering Basics

Exam-friendly notes following the official R-2021 syllabus.

1. Origin of Value Engineering

Value engineering developed from the need to obtain the required function of a product or system at an appropriate overall cost. The approach focuses on function rather than simply reducing the purchase price or removing features.

In engineering practice, this means asking: What function is required? What does it cost? What alternatives can perform the same function?

2. Meaning and definition

Value engineering: a systematic approach for analysing the functions of a product, component, system or service and seeking alternatives that provide the required function with appropriate value.

Value Analysis (VA) applies the same function-oriented thinking to an existing product or system. Value Engineering (VE) is commonly associated with applying the approach during development or planning, before major commitments are made.

3. Value Management

Value management is the broader management approach that coordinates value-focused decisions throughout a project or product life cycle. It provides the framework within which value engineering and value analysis activities can be carried out.

4. Value Analysis vs Value Engineering

AspectValue AnalysisValue Engineering
Typical focusExisting product, process or systemProduct, process or system under development/planning
TimingAfter the design or system existsEarlier in the development/design process
PurposeImprove value by analysing existing functions and costsBuild required functions into the solution with good value

5. Value Analysis vs traditional cost reduction

Traditional cost reduction may focus directly on reducing expenditure. Value engineering instead begins with function. A lower-cost alternative is acceptable only when the required function and necessary performance are maintained.

  • Cost reduction: “How can the cost be reduced?”
  • Value engineering: “What function is required, what is it worth, and what alternatives can provide it?”

6. Types of value functions

Basic function

The fundamental purpose for which a product, component or system exists. Removing the basic function means the item can no longer perform its essential purpose.

Secondary function

A supporting or additional function that helps the product perform, communicate, satisfy users or provide other desirable characteristics. Secondary functions may sometimes be modified or eliminated after proper analysis.

7. Cost and worth

Cost represents the resources or expenditure associated with providing a function or product.

Worth is the value assigned to the function based on the minimum cost of providing the required function adequately through an acceptable alternative.

Key idea: A major VE opportunity exists when the cost associated with a function is significantly greater than the function's required worth.

8. Creativity in Value Engineering

Creativity is required to generate alternative ways of performing a required function. During idea generation, the team should avoid judging ideas too early. Evaluation and selection are carried out after sufficient alternatives have been generated.

Brainstorming is one of the creative techniques explicitly included later in the CME338 syllabus.

9. Uses and applications

  • Product and component development
  • Manufacturing and process improvement
  • Cost and function evaluation
  • Maintenance and repair activities
  • Non-hardware projects
  • Product life-cycle decisions

10. Advantages

  • Encourages systematic function analysis.
  • Generates alternative design or process solutions.
  • Can improve value without simply sacrificing required performance.
  • Supports multidisciplinary decision-making.
  • Helps identify unnecessary cost associated with functions.

11. Limitations

  • Requires accurate understanding of required functions.
  • Good alternatives may require significant creativity and technical knowledge.
  • Implementation can face organisational resistance.
  • Short-term cost reduction should not be confused with improved life-cycle value.
  • Safety, reliability, quality and regulatory requirements cannot be compromised.

Exam points

  • Define value engineering, value analysis and value management.
  • Differentiate value analysis and value engineering.
  • Explain basic and secondary functions with suitable examples.
  • Explain the concepts of cost and worth.
  • Discuss the uses, applications, advantages and limitations of value analysis.
  • Explain the role of creativity in value engineering.

Quick revision

Remember: Function → Cost → Worth → Alternatives → Value.
