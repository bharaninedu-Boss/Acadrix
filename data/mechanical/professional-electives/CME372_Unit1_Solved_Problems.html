Fundamentals of Computer Graphics • R-2021 Professional Elective

Problem 1 — 2D Translation

Given: Point P(4, 6), translation tx = 8, ty = −3.
Find: transformed point.
Formula: x′ = x + tx; y′ = y + ty.
Substitute: x′ = 4 + 8 = 12; y′ = 6 − 3 = 3.
Final answer: P′(12, 3).

Problem 2 — 2D Scaling

Given: P(5, −2), sx = 2, sy = 3.
Formula: x′ = sxx; y′ = syy.
Substitute: x′ = 2(5) = 10; y′ = 3(−2) = −6.
Final answer: P′(10, −6).

Problem 3 — 2D Rotation

Given: P(1, 0), rotation θ = 90° counter-clockwise about origin.
Formula: x′ = x cosθ − y sinθ; y′ = x sinθ + y cosθ.
Substitute: cos90° = 0, sin90° = 1.
x′ = 1(0) − 0(1) = 0.
y′ = 1(1) + 0(0) = 1.
Final answer: P′(0, 1).

Problem 4 — Combined Scaling and Translation

Given: P(3, 4). First scale by sx=2, sy=3, then translate by (5, −2).
Step 1 — Scale: x₁ = 2(3) = 6; y₁ = 3(4) = 12.
Step 2 — Translate: x₂ = 6 + 5 = 11; y₂ = 12 − 2 = 10.
Final answer: P′(11, 10). Order matters: scaling followed by translation is not generally identical to translation followed by scaling.

Problem 5 — Rotation About a General Point

Given: Point P(6, 2) is rotated 90° counter-clockwise about C(2, 1).
Step 1 — Translate centre to origin: x = 6 − 2 = 4; y = 2 − 1 = 1.
Step 2 — Rotate: x′ = 4(0) − 1(1) = −1; y′ = 4(1) + 1(0) = 4.
Step 3 — Translate back: X = −1 + 2 = 1; Y = 4 + 1 = 5.
Final answer: P′(1, 5).

Problem 6 — Line Drawing / Pixel Decision Practice

Given: A raster line is required from (2,2) to (7,5).
Find: the basic slope and explain the decision path concept.
Step 1: Δx = 7 − 2 = 5; Δy = 5 − 2 = 3.
Step 2: slope = Δy/Δx = 3/5 = 0.6.
Conclusion: Because the slope magnitude is less than 1, a line rasterisation method such as an incremental/Bresenham-style approach can step primarily in x while deciding whether y should increment at each step. The exact pixel decisions depend on the selected algorithm.

Problem 7 — Viewing/Clipping Concept

Given: A viewing window is x = 0 to 100 and y = 0 to 80. A point is P(120, 30).
Check: x = 120 lies outside the x-range 0–100, while y = 30 lies inside 0–80.
Final: P is outside the viewing window and its graphical contribution is clipped for that view.
