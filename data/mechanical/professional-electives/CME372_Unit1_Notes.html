CME372 — Unit I: Fundamentals of Computer Graphics

R-2021 • CAD and CAE

2 Marks12 Marks

Official syllabus scope: design process, CAD, computer graphics, coordinate systems, 2D/3D transformations, point/line/circle drawing algorithms, clipping, viewing transformation and standards for computer graphics.

1. Computer-Aided Design

CAD is the use of computer systems and software to create, modify, analyse, document and communicate engineering designs. It improves drafting accuracy, design iteration, documentation and data reuse.

Basic CAD design process

Requirement → concept → geometric model → analysis/evaluation → modification → documentation → manufacturing data.

2. Computer Graphics

Computer graphics deals with creating, representing, manipulating and displaying graphical information. In mechanical CAD, graphics represent 2D drawings and 3D geometry.

3. Coordinate Systems

SystemUse
CartesianRepresents points using x, y and z coordinates.
World coordinate systemFixed reference for the complete model or scene.
Local/model coordinatesConvenient for defining individual components before positioning them.
Screen/device coordinatesUsed for final display or output-device representation.

4. 2D Transformations

Translation

x′ = x + tx    y′ = y + ty

Scaling

x′ = sxx    y′ = syy

Rotation

x′ = x cos θ − y sin θ
y′ = x sin θ + y cos θ

Reflection produces a mirror image about a selected axis or line.

5. 3D Transformations

Three-dimensional CAD models use x, y and z coordinates. Translation, scaling and rotation extend to three dimensions. Homogeneous coordinates and transformation matrices allow multiple transformations to be combined systematically.

6. Graphic Primitives and Drawing Algorithms

  • Point: basic location entity.
  • Line: straight segment between locations.
  • Circle: defined using centre/radius or equivalent geometric data.
  • Polygon: connected sequence of line segments.

Point/line/circle drawing algorithms: computer algorithms determine which display pixels should represent ideal geometric primitives. Incremental decision methods reduce unnecessary computation.

7. Clipping

Clipping removes portions of graphical objects outside the selected viewing region.

  • Reduces unnecessary display processing.
  • Prevents objects outside the viewing region from appearing.
  • Improves graphics-pipeline efficiency.

8. Viewing Transformation

Viewing transformation maps model/world coordinates into a coordinate system suitable for display.

Conceptual pipeline: Model coordinates → World coordinates → Viewing transformation → Projection/device coordinates → Display.

9. Standards for Computer Graphics

Graphics standards improve portability and consistency between graphics systems and software by defining common ways to represent, exchange or display graphical information.

10. CAD Benefits

  • Accurate geometric representation.
  • Rapid design modification.
  • Reusable design data.
  • Assembly and interference checking.
  • Integration with CAE and manufacturing systems.
  • Better documentation and visual communication.
