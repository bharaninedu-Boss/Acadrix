1. Computer-Aided Design

CAD is the use of computer systems and software to create, modify, analyse, document and communicate engineering designs. CAD improves drafting accuracy, design iteration, documentation and data reuse.

Basic CAD design process

Requirement → concept → geometric model → analysis/evaluation → modification → documentation → manufacturing data.

2. Computer Graphics

Computer graphics deals with creating, representing, manipulating and displaying graphical information. In mechanical CAD, graphics are used to represent 2D drawings and 3D geometry.

3. Coordinate Systems

SystemUse
CartesianRepresents points using x, y and z coordinates.
World coordinate systemFixed reference for the complete model or scene.
Local/model coordinatesConvenient for defining individual components before positioning them.
Screen/device coordinatesUsed for final display or output device representation.

4. 2D Transformations

Translation

Moves an object without changing its size or orientation.

x′ = x + tx    y′ = y + ty

Scaling

x′ = sxx    y′ = syy

Scaling changes size. If both scale factors are equal, the transformation is uniform scaling.

Rotation

x′ = x cos θ − y sin θ
y′ = x sin θ + y cos θ

For rotation about the origin, θ is measured according to the selected positive rotation convention.

Reflection

Reflection produces a mirror image about a selected axis or line.

5. 3D Transformations

Three-dimensional CAD models use x, y and z coordinates. Translation, scaling and rotation are extended to three dimensions. Homogeneous coordinates and transformation matrices allow multiple transformations to be combined systematically.

6. Graphic Primitives

  • Point: basic location entity.
  • Line: straight segment between locations.
  • Circle: defined using centre/radius or equivalent geometric data.
  • Polygon: connected sequence of line segments.
  • Curve/surface: higher-level geometry used for engineering shapes.

Line drawing idea

Computer algorithms determine which display pixels should represent an ideal geometric line. Efficient incremental methods avoid unnecessary floating-point computation.

7. Clipping

Clipping removes portions of graphical objects that lie outside the selected viewing region.

Why clipping is needed

  • Reduces unnecessary display processing.
  • Prevents objects outside the viewing region from appearing.
  • Improves efficiency of graphical pipelines.

Line and polygon clipping algorithms determine the visible portions inside the clipping window.

8. Viewing Transformation

Viewing transformation maps model/world coordinates into a coordinate system suitable for display. It controls what part of the model is seen and how it is positioned on the viewing surface.

Conceptual pipeline: Model coordinates → World coordinates → Viewing transformation → Projection/device coordinates → Display.

9. Computer Graphics Standards

Standards improve portability and consistency between graphics systems and software. They define ways to represent, exchange or display graphical information.

10. CAD Benefits

  • Accurate geometric representation.
  • Rapid design modification.
  • Reusable design data.
  • Assembly and interference checking.
  • Integration with CAE and manufacturing systems.
  • Better documentation and visual communication.
