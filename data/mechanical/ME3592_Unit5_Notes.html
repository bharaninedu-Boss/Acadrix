1. Lasers in Metrology

1.1 Why lasers are useful for measurement

A laser produces highly directional, coherent and nearly monochromatic optical radiation. These characteristics make laser-based systems useful for precise displacement, length, alignment and scanning measurements.

  • Very narrow and well-directed beam.
  • Stable wavelength provides a reference for interferometric measurement.
  • Non-contact measurement is possible.
  • Suitable for long measurement paths.
  • High-speed scanning can be integrated with production inspection.
  • Can be combined with automated data acquisition and CNC/inspection systems.
LASER SOURCE → OPTICAL PATH → TARGET / REFLECTOR → DETECTOR → SIGNAL PROCESSING → MEASUREMENT

1.2 Laser scan micrometer

A laser scan micrometer is a non-contact dimensional measuring system in which a laser beam is scanned across a part and the interruption of the beam is used to determine a dimension such as diameter or width.

Emitter →→→→→→→→→ Receiver ┌──────────────┐ │ WORKPIECE │ ← beam interruption └──────────────┘ ↑ ↑ scan limits / measured dimension Optical signal → electronics → dimension display

Working: the optical system establishes a calibrated scan path; the workpiece interrupts the beam; the system detects the beginning and end of interruption; the electronics convert the timing/position information into a dimensional value.

Applications: wires, shafts, tubes, fibres, small cylindrical parts and continuous production inspection.

Advantages: non-contact, fast, suitable for delicate/hot/moving parts and easily automated.

Limitations: optical contamination, surface reflectivity, alignment and environmental conditions can influence measurement.

2. Laser Interferometers

2.1 Principle

Laser interferometry measures displacement by comparing optical paths. A beam is split into measurement and reference paths; after recombination, the phase difference produces an interference signal. A change in optical path produces a corresponding change in the interference condition.

┌──────── Reference path ────────┐ Laser → Beam splitter ──┤ │ └──────── Measurement path → Reflector │ ▼ Recombined beams │ ▼ Detector │ ▼ Electronics / display

2.2 Fringe/counting idea

When the optical path changes, interference fringes move. Counting the fringe changes, together with the known wavelength and optical arrangement, allows displacement to be determined. The exact conversion factor depends on the interferometer configuration; therefore a problem must use the configuration specified in the question.

2.3 Full-working example — displacement from fringe count

Given: A simplified double-pass interferometer arrangement uses a laser wavelength of 632.8 nm. A displacement produces 1000 complete fringe cycles.

For this specified double-pass arrangement:

N = 2dλ  ⇒  d = Nλ2

Step 1 — convert wavelength: λ = 632.8 nm = 632.8 × 10−9 m.

Step 2 — substitute:

d = (1000 × 632.8 × 10−9)/2 m

Step 3 — calculate: d = 3.164 × 10−4 m = 0.3164 mm.

Final answer: displacement = 0.3164 mm.

Exam caution: Do not blindly use λ/2 or λ/4. First identify whether the optical path is single-pass, double-pass or another arrangement shown in the question.

3. Applications: Straightness and Alignment

3.1 Straightness measurement using a laser

Purpose: determine how much a machine slide, guideway or structural line deviates from the required straight reference.

  1. Set the laser source and optical reference along the measurement path.
  2. Align the optical system carefully.
  3. Move the machine element or receiver through defined positions.
  4. Record displacement/deviation at each position.
  5. Construct the deviation profile.
  6. Compare maximum deviation with the specified straightness requirement.

Why laser methods are valuable: long reference distance, non-contact sensing, high sensitivity and compatibility with computerised error mapping.

3.2 Alignment measurement

Laser alignment establishes a reference line/axis and checks whether machine elements are positioned relative to that reference. It is useful for machine-tool installation, shaft/axis alignment and inspection of large structures.

4. Ball Bar Tests

A ball bar is a calibrated length-changing device with spherical magnetic/kinematic connections used to evaluate the geometric performance of a CNC machine tool, particularly circular motion accuracy. The test compares the commanded circular path with the actual path.

Machine spindle / tool point ●──── calibrated ball bar ────● machine table CNC commands circular interpolation ↓ Actual motion is recorded ↓ Circular error profile ↓ Diagnostic machine condition

Important idea

The resulting circular profile can reveal errors such as backlash, servo mismatch, scale-related effects, squareness and geometric inaccuracies. The exact diagnostic interpretation depends on the test setup and software used.

Advantages: relatively quick, automated data collection, useful for machine acceptance/diagnosis and capable of revealing several error sources from a circular test.

5. Computer Aided Metrology — CMM

5.1 Basic concept

A Coordinate Measuring Machine (CMM) determines the coordinates of points on a component in a defined coordinate system. A probe senses a feature and the machine records its X, Y and Z coordinates. Software then uses these points to calculate dimensions, form/position relationships and other inspection results.

Z axis ↑ │ Probe │ ↓ ┌───────┼──────● │ │ │ │ WORKPIECE │ └───────────────┘ → X axis / Y axis Structure + guideways + scales + probe + controller + software

5.2 Main elements

  • Rigid machine structure and guideways.
  • Precision linear measurement/scales on machine axes.
  • Probe system.
  • Controller and motion system.
  • Computer and metrology software.
  • Workholding/accessories.

7. CMM Constructional Features, Probes, Accessories and Software

7.1 Constructional features

  • Stable base and machine structure.
  • Precision guideways for controlled axis motion.
  • Low-error linear scales/encoders.
  • Controlled probing system.
  • Environmental protection/temperature control where required for high accuracy.

7.2 Probes

Contact probes physically touch the surface to collect points. Scanning probes can collect many points while moving along a surface. Non-contact optical sensors may also be integrated in suitable CMM systems.

7.3 Accessories

Common accessories include stylus extensions, probe-changing systems, rotary/indexing devices, fixtures, workholding arrangements and reference artefacts. The selected accessory should not compromise access, rigidity or measurement accuracy.

7.4 Software

CMM software handles coordinate-system setup, feature measurement, geometric calculations, alignment, reporting, inspection planning and comparison with CAD or nominal data where supported.

8. CMM Applications

Dimensional inspectionLengths, diameters, distances and feature sizes.
Geometric inspectionForm, orientation and location relationships.
Complex profilesFree-form and contoured components.
CAD comparisonMeasured geometry can be compared with nominal design data when supported by the software workflow.

9. Multi-Sensor CMMs

A multi-sensor CMM combines more than one sensing principle so that different features can be measured with an appropriate sensor. A system may combine contact probing with optical/vision sensing, depending on the machine configuration.

SensorUseful when
Contact probePrecise discrete geometric points and robust dimensional inspection.
Optical/vision sensorSmall, delicate, flat or visually accessible features where non-contact measurement is useful.
Other integrated sensorsSelected surface or geometry measurements according to the system specification.

Benefit: one coordinate framework can support different measurement tasks, reducing repeated setups and improving inspection flexibility.

10. Machine Vision

10.1 Basic concept

Machine vision is a computer-based system that acquires images of a part, processes the image and makes a measurement, classification or inspection decision.

ILLUMINATION → CAMERA / OPTICS → IMAGE ACQUISITION → IMAGE PROCESSING → FEATURE EXTRACTION → DECISION / CONTROL ↑ ↓ └────────────────────── feedback / production response ───────────────────────────────────┘

10.2 Elements

  1. Object and presentation: component is positioned consistently.
  2. Lighting: creates useful contrast and reveals the required feature.
  3. Optics: forms the image.
  4. Camera/sensor: converts the optical image into data.
  5. Processing: filtering, segmentation, edge/feature extraction and measurement.
  6. Decision logic: accepts, rejects, classifies or triggers a control action.

10.3 Applications

  • Dimensional and profile inspection.
  • Presence/absence checking.
  • Surface/defect inspection.
  • Identification and sorting.
  • Assembly verification.
  • On-line production monitoring.

11. On-line and In-process Monitoring

On-line monitoring measures or inspects parts during the production flow. In-process monitoring obtains information while the manufacturing process is taking place so that deviations can be detected early.

A typical closed-loop concept is:

PROCESS → MEASUREMENT → DATA ANALYSIS → QUALITY DECISION → CORRECTIVE ACTION → PROCESS

Benefits: early detection, reduced scrap, reduced rework, faster feedback and better process control. The measurement system must be fast enough for production and robust against coolant, chips, vibration, lighting and other industrial conditions as applicable.

12. Computed Tomography (CT) in Metrology

Industrial computed tomography uses X-ray projections acquired from different viewing directions and computational reconstruction to produce a representation of internal and external structure. This makes CT particularly useful where internal geometry cannot be inspected completely by ordinary external measurements.

X-RAY SOURCE →→ [ WORKPIECE ] →→ DETECTOR ↘ rotate / multiple views ↙ ↓ projection data ↓ reconstruction ↓ 3D volumetric data ↓ measurement / inspection

Measurement workflow

  1. Prepare and position the component.
  2. Select suitable X-ray/scan settings according to the system and part.
  3. Acquire multiple projections while the part is rotated/positioned as required.
  4. Reconstruct the volumetric dataset.
  5. Define the required geometry/features in the reconstructed data.
  6. Perform dimensional or defect analysis using metrology software.

Advantages

  • Access to internal as well as external geometry.
  • Non-destructive inspection in suitable applications.
  • Useful for complex components and internal channels.
  • Combines inspection and measurement information.

Limitations

  • Measurement accuracy depends on system calibration and scanning/reconstruction conditions.
  • Material density and part size influence X-ray penetration and image quality.
  • Artefacts and reconstruction effects can affect results.
  • Equipment and data-processing requirements are comparatively high.

13. White-Light Scanners

White-light scanning is an optical 3D measurement approach that captures surface geometry without physical contact. The system projects or observes structured optical information and uses the captured image information to reconstruct surface coordinates.

WHITE / STRUCTURED LIGHT ↓ WORKPIECE SURFACE ↓ reflected / structured pattern CAMERA(S) ↓ IMAGE PROCESSING ↓ 3D POINT CLOUD ↓ SURFACE / CAD COMPARISON / INSPECTION

Typical uses

  • Rapid 3D digitisation.
  • Free-form surface inspection.
  • Reverse-engineering support.
  • Large-area dimensional comparison.
  • Surface deformation and shape inspection.

Important limitation: optical measurement can be affected by surface reflectivity, transparency, colour, ambient light, occlusion and surface preparation.
