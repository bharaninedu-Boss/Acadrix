ME3591 – Design of Machine Elements

ACADRIX Formula Sheet • Anna University R-2021 • Semester 5

Notation rule: Use proper engineering symbols in the exam: σ, τ, σ₁, σ₂, σₓ, σᵧ, τₓᵧ, Sᵧₜ, Sᵤₜ, Sₑ, S′ₑ, M, T, d, b, t, l, W, N, etc. Do not write unclear forms such as “si” or “se” when a subscripted symbol is intended.

1. Fundamental Design

FOS = Failure stress / Allowable stress
σ = P/A
τ = P/Aₛ
σᵦ = M/Z
τ = T/Zₚ
σ₁, σ₂ = (σₓ + σᵧ)/2 ± √[((σₓ − σᵧ)/2)² + τₓᵧ²]
τₘₐₓ = (σ₁ − σ₂)/2
Symbols: P = load; A = cross-sectional area; Aₛ = shear area; M = bending moment; T = torque; Z = section modulus; Zₚ = polar section modulus; σ = normal stress; τ = shear stress.

2. Shafts and Keys

T = 60P/(2πN)   [P in W, T in N·m]
T = (π/16)τd³   (solid circular shaft)
σᵦ = 32M/(πd³)   (solid circular shaft)
Combined loading: Apply the failure theory specified in the question (for example, maximum shear stress theory or distortion-energy theory). Do not mix the equivalent-stress relations between theories.
τₖ = 2T/(dbl)
σ꜀ = 4T/(dtl)
Key symbols: d = shaft diameter; b = key width; t = key thickness; l = key length; τₖ = key shear stress; σ꜀ = key crushing stress.

3. Couplings and Power Screws

d₂ = (d + d꜀)/2
tan α = Lead/(πd₂)
μ′ = μ sec β
φ = tan⁻¹(μ′)
Tᵣ = (Wd₂/2) tan(φ + α)
Tₗ = (Wd₂/2) tan(φ − α)
η = tan α / tan(φ + α)
Power-screw symbols: d = nominal/major diameter; d꜀ = core diameter; d₂ = mean diameter; α = helix angle; μ = coefficient of friction; β = thread half-angle; μ′ = equivalent friction coefficient for trapezoidal thread; φ = friction angle; W = axial load; Tᵣ = torque to raise; Tₗ = torque to lower; η = efficiency.

4. Springs, Flywheels and Bearings

k = W/δ
T = (T₁ − T₂)D/2
p = W/(Ld)
v = πdN/60
Pₗ = fWv
Symbols: k = spring stiffness; δ = deflection; T₁, T₂ = belt tensions; D = pulley diameter; p = bearing pressure; L = bearing length; d = journal diameter; v = journal surface speed; f = coefficient of friction; Pₗ = friction power loss.

5. Fatigue and Fluctuating Stress

S′ₑ = 0.5Sᵤₜ
Sₑ = KₐKᵦK꜀KᵈS′ₑ
Kf = 1 + q(Kt − 1)
σₐ = (σₘₐₓ − σₘᵢₙ)/2
σₘ = (σₘₐₓ + σₘᵢₙ)/2
Fatigue symbols: Sᵤₜ = ultimate tensile strength; Sᵧₜ = tensile yield strength; S′ₑ = unmodified endurance limit; Sₑ = corrected endurance limit; Kₐ = surface factor; Kᵦ = size factor; K꜀ = reliability factor; Kᵈ = miscellaneous/modifying factor; Kt = theoretical stress-concentration factor; q = notch sensitivity; Kf = fatigue stress-concentration factor; σₐ = alternating stress; σₘ = mean stress.

6. Welded Joints

Fillet-weld throat = 0.707s
τ = P/(0.707sL)
Symbols: s = fillet weld size; L = total effective weld length; P = applied load. For eccentric loading, calculate direct shear and moment-induced stress from the weld-group geometry, then combine them as required.
