🧮 4. Numerical Attack List

  1. Write Given data with units.
  2. Write To Find.
  3. Draw the FBD/sketch if loads or geometry matter.
  4. Convert to a consistent unit system.
  5. Write the governing formula.
  6. Substitute every actual value into the formula.
  7. Show arithmetic and intermediate values.
  8. Continue to the next formula rather than jumping to the result.
  9. Check strength/rigidity/safety requirements.
  10. Select a practical standard dimension where required and verify it.

Locked ACADRIX numerical standard: Given → Formula → actual-value substitution → arithmetic → intermediate result → next formula → substitution → final answer.

  • Why are keys used?
  • What is critical speed?

  • Define cotter joint.
  • What is a knuckle joint?
  • Why is fillet-weld throat 0.707s?
  • State one advantage of a power screw.

Unit IV

  • What is spring surge?
  • State the function of a flywheel.
  • What is spring stiffness?
  • Why is a connecting rod designed for fluctuating load?

Unit V

  • Define hydrodynamic lubrication.
  • What is Sommerfeld number?
  • What is a rolling-contact bearing?
  • State the purpose of a seal.
