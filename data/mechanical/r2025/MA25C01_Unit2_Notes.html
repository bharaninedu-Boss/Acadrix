Unit II — Functions of Several Variables

MA25C01 · R-2025 · Exam-oriented notes

1 Mark3 Marks12 Marks

Syllabus: partial derivatives, chain rule, total derivative, maxima/minima of two variables, Lagrange multipliers and engineering applications.

1. Core Theory

1.1 Functions of Several Variables

A function of two variables is written z=f(x,y). Each permitted ordered pair (x,y) has one output z. The domain is a region in the xy-plane. In engineering, a response may depend simultaneously on variables such as position, temperature, pressure, dimensions or time.

1.2 Partial Derivatives

The partial derivative with respect to x measures the change in z as x varies while y is held constant. Similarly, fᵧ measures change with y while x is held constant.

NotationMeaning
fₓ=∂f/∂xDifferentiate with respect to x; treat y as constant.
fᵧ=∂f/∂yDifferentiate with respect to y; treat x as constant.
fₓₓ, fᵧᵧSecond partial derivatives with respect to the same variable.
fₓᵧ, fᵧₓMixed partial derivatives.

Example: if f=x²y+3y², then fₓ=2xy and fᵧ=x²+6y.

1.3 Higher-Order and Mixed Partials

Differentiate first with respect to one variable and then again as required. Under appropriate continuity conditions, mixed partial derivatives are equal: fₓᵧ=fᵧₓ.

1.4 Chain Rule

If z=f(x,y), where x=x(t) and y=y(t), then

dz/dt=fₓ(dx/dt)+fᵧ(dy/dt)

The chain rule accounts for every path through which a change in an intermediate variable affects z.

1.5 Total Derivative and Total Differential

For small changes in x and y, the first-order change in z is approximated by the total differential:

dz=fₓdx+fᵧdy

The total derivative is useful when dependent variables change simultaneously.

1.6 Maxima and Minima of Two Variables

For an interior stationary point, solve fₓ=0 and fᵧ=0. Then calculate

D=fₓₓfᵧᵧ−(fₓᵧ)²
ConditionResult
D>0, fₓₓ>0Local minimum
D>0, fₓₓ<0Local maximum
D<0Saddle point
D=0Test inconclusive

1.7 Lagrange Multipliers

For maximising or minimising f(x,y) subject to g(x,y)=c, form the condition ∇f=λ∇g and solve it together with the constraint.

fₓ=λgₓ
fᵧ=λgᵧ
g(x,y)=c

1.8 Engineering Applications

  • Optimising dimensions for minimum material or maximum performance.
  • Studying temperature variation with position.
  • Analysing a response depending on multiple design variables.
  • Finding constrained optimum values in design problems.

5. 12-Mark Answer Framework

For stationary-point problems: write f(x,y) → calculate fₓ and fᵧ → set both to zero → solve candidate points → calculate fₓₓ, fᵧᵧ, fₓᵧ → calculate D → classify → state conclusion.
For Lagrange multipliers: write objective and constraint → calculate gradients → write ∇f=λ∇g → solve simultaneous equations → calculate objective value → state maximum/minimum interpretation.
