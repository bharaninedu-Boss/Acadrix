Unit I — Differential Calculus

MA25C01 Applied Calculus · R-2025 · B.E. Mechanical Engineering

Exam-friendly ACADRIX study notes aligned to the verified R-2025 syllabus topics.

Syllabus scope: Functions, graph of functions, new functions, limits, continuity, limits at infinity, derivative, maxima/minima, mean value theorem and the effect of derivatives on graph shape.

1. Functions

A function assigns each allowed input x exactly one output f(x). The domain is the set of permitted inputs and the range is the set of resulting outputs.

  • Polynomial functions are defined for all real x.
  • For a rational function, denominator ≠ 0.
  • For an even root, the expression inside the root must be ≥ 0 when working over the reals.

3. Limits

The limit describes the value that f(x) approaches as x approaches a point. For a finite limit, the left-hand and right-hand limits must agree.

Useful first steps: direct substitution → factor/cancel where valid → rationalise radicals where useful → use standard limit results.

Important standard result: lim(x→0) sin x / x = 1, with x measured in radians.

4. Continuity

A function is continuous at x=a when f(a) exists, lim(x→a) f(x) exists, and the two are equal.

5. Limits at Infinity

For rational functions, compare the highest powers of x. If numerator and denominator have the same degree, the limit at ±∞ is the ratio of their leading coefficients.

7. Maxima and Minima

Stationary points can occur where f'(x)=0 or where the derivative does not exist. Test candidate points using the sign of f'(x) or an appropriate second-derivative test.

  • f''(a)>0 → local minimum at a stationary point.
  • f''(a)<0 → local maximum at a stationary point.
  • f''(a)=0 → test further; the result is inconclusive.

8. Mean Value Theorem

If a function is continuous on [a,b] and differentiable on (a,b), there is at least one c in (a,b) such that f'(c)=(f(b)-f(a))/(b-a).

9. Effect of Derivatives on Graph Shape

  • f'(x)>0: function increasing.
  • f'(x)<0: function decreasing.
  • f''(x)>0: concave upward.
  • f''(x)<0: concave downward.
Exam workflow: identify the function and domain → find the required limit/derivative → simplify carefully → identify critical points → classify them → interpret the result in the engineering context.
