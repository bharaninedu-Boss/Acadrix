1. Core Notes

1.1 Antiderivatives and Indefinite Integrals

An antiderivative of f(x) is a function F(x) such that F′(x)=f(x). Hence ∫f(x)dx=F(x)+C. The constant C is essential because differentiation removes constants.

1.2 Definite Integrals

For a continuous function with antiderivative F, ∫ₐᵇf(x)dx=F(b)−F(a). It represents signed accumulation; areas below the x-axis contribute negatively.

1.3 Fundamental Theorem of Calculus

If f is continuous, the accumulation function satisfies d/dx[∫ₐˣf(t)dt]=f(x). The evaluation form is ∫ₐᵇf(x)dx=F(b)−F(a) when F′=f.

1.4 Net Change Theorem

If a quantity F changes at rate F′(t), its total change over [a,b] is F(b)−F(a)=∫ₐᵇF′(t)dt. Examples include displacement from velocity and accumulated volume from flow rate.

1.5 Improper Integrals

An improper integral has an infinite interval or an unbounded integrand. Replace the problematic endpoint by a limit. For example, ∫ₐ∞f(x)dx=lim(b→∞)∫ₐᵇf(x)dx. For ∫₁∞1/xᵖdx, convergence occurs for p>1 and divergence for p≤1.

1.6 Area of a Region

For vertical slices between upper and lower curves, A=∫ₐᵇ[upper−lower]dx. First find intersection points and verify which curve is above on the interval. If horizontal slices are simpler, use dy.

1.7 Arc Length

For y=f(x) on [a,b], L=∫ₐᵇ√(1+[f′(x)]²)dx. For x=g(y), use L=∫√(1+[g′(y)]²)dy over the appropriate y-limits.

1.8 Surface Area of Revolution

When y=f(x) is revolved about the x-axis, S=2π∫ₐᵇ|y|√(1+[y′]²)dx. The structure is S=∫2π(radius)ds.

4. 12-Mark Preparation

  • Evaluate a substantial definite or indefinite integral using an appropriate integration method, showing every major step.
  • Evaluate an improper integral using the limiting process and clearly state whether it converges or diverges.
  • Find the area bounded by two or more curves: obtain intersections, determine the correct region and evaluate the integral.
  • Find the arc length of a specified curve over a given interval, including correct limits and simplification.
  • Find the surface area generated by revolving a curve about an axis and identify the radius and differential arc length.
  • Solve a Net Change application in which a rate such as velocity, flow or production rate is integrated to obtain total change.

5. How to Write a 12-Mark Answer

  1. Write the given function/curve and required quantity.
  2. State the governing formula.
  3. Find intersections or limits if required.
  4. Set up the integral clearly before evaluating.
  5. Show substitutions and important algebraic steps.
  6. Give the final numerical/exact result with units when applicable.
  7. State convergence/divergence or physical interpretation where relevant.
