ME3591 – Solved Problems

ACADRIX • R-2021 • Verified numerical practice

These solutions are based on the ME3591 question-paper problems already verified for ACADRIX. Standard dimensions should be selected from the PSG Design Data Book where applicable. Intermediate values are shown so the calculation can be checked.

1. Overhang Crank – Q11(a)

Given: P = 1 kN, Syt = 400 MPa, FOS = 2. Vertical distance = 500 mm; eccentricity = 50 + 100 + 25 = 175 mm. Maximum shear stress theory.

Allowable shear stress = Syt/(2 × FOS) = 400/(2 × 2) = 100 MPa.
Bending moment, M = 1000 × 500 = 500 × 10³ Nmm.
Torque, T = 1000 × 175 = 175 × 10³ Nmm.
For a solid circular section, σb = 32M/(πd³), τ = 16T/(πd³).
Maximum shear condition: 100 = √[(σb/2)² + τ²].
Answer: d ≈ 30 mm.

2. Fatigue Plate – Q11(b)

Given: completely reversed axial load ±50 kN, Sut = 630 MPa, reliability = 90%, FOS = 2, size factor = 0.85, notch radius = 5 mm, minimum plate width = 50 mm.

Unmodified endurance limit: S'e = 0.5Sut = 315 MPa.
Using the applicable PSG/Bhandari fatigue factors: Ka = 0.76, Kb = 0.85, Kc = 0.897, Kd = 0.496.
Corrected endurance limit: Se = Ka × Kb × Kc × Kd × S'e = 90.54 MPa.
With the specified notch treatment, Kf = 2.016. For the design condition used here, allowable alternating stress = 0.8Se/FOS = 36.215 MPa.
σa = P/(bt), so 36.215 = 50000/(50t).
t = 27.6 mm → adopt 28 mm.

Important: the 50 kN load in the actual paper is used here; do not substitute a different example load.

3. Square Key – Q12(a)

Given: d = 25 mm, P = 15 kW, N = 720 rpm, key steel 50C4, Syt = 460 MPa, FOS = 3.

T = 60P/(2πN) = 60(15000)/(2π × 720) = 198944 Nmm.
Allowable shear = 460/(2 × 3) = 76.67 MPa; allowable crushing = 460/3 = 153.33 MPa.
For a square key, theoretical b ≈ t ≈ d/4 = 6.25 mm.
Required length from shear is about 33.2 mm. Check crushing as well.
Adopt PSG/practical standard key: 7 × 7 × 35 mm.

4. Muff Coupling – Q12(b)

Given: P = 25 kW, N = 360 rpm, shafts 30C8, Syt = 400 MPa, sleeve FG200 Sut = 200 MPa, FOS = 4 for shaft/key and 6 for sleeve.

T = 60(25000)/(2π × 360) = 663146 Nmm.
Allowable shaft shear = 400/(2 × 4) = 50 MPa.
Calculated shaft diameter ≈ 40.73 mm. Select the next suitable PSG standard size.
Adopt shaft diameter d = 45 mm.
Using the applicable sleeve proportion, D ≈ 2d + 13 = 103 mm → 105 mm; L ≈ 3.5d = 157.5 mm → 160 mm.
Sleeve shear stress with D = 105 mm is about 3.02 MPa, below the allowable value 200/(2 × 6) = 16.67 MPa.
For a 45 mm shaft, select the applicable PSG key: 14 × 9 mm; required key length is about 80 mm.
Final: shaft d = 45 mm; sleeve D = 105 mm, L = 160 mm; key = 14 × 9 × 80 mm.

5. Double-Threaded Trapezoidal Power Screw – Q13(a)

Given: W = 300 kN, nominal diameter d = 100 mm, pitch = 12 mm, double thread, μ = 0.15, collar friction neglected.

For ISO metric trapezoidal thread, mean diameter used = d2 = 94 mm for the stated geometry.
Lead = 2 × pitch = 24 mm.
Thread half-angle β = 15°. Equivalent friction coefficient μ' = μ sec15° = 0.15529.
Helix angle: α = tan⁻¹[24/(π × 94)] = 4.646°.
Friction angle: φ = tan⁻¹(0.15529) = 8.827°.
Raising torque = Wd2/2 × tan(φ + α) ≈ 3378 N·m.
Lowering torque = Wd2/2 × tan(φ − α) ≈ 1031 N·m.
Efficiency ≈ 33.9%.

6. Rectangular Fillet Weld – Q13(b)

Given: P = 25 kN, eccentricity = 500 mm, weld rectangle = 150 × 100 mm, permissible weld shear = 75 N/mm².

Fillet-weld throat = 0.707s.
Total weld length = 2(150 + 100) = 500 mm.
Direct shear = 25000/(0.707s × 500) = 70.72/s N/mm².
Moment M = 25000 × 500 = 12.5 × 10⁶ Nmm.
Using the rectangular weld-group property, Z ≈ 15907.5s mm³. Bending stress ≈ 785.8/s N/mm².
Apply the maximum-shear combination with the permissible value 75 N/mm².
s ≈ 5.32 mm → adopt 6 mm fillet weld.

7. Hydrodynamic Journal Bearing – Q14(b)

Given: W = 3.2 kN, N = 1490 rpm, d = 50 mm, L = 50 mm, radial clearance c = 0.05 mm, viscosity = 25 cP.

Bearing pressure p = W/(Ld) = 3200/(50 × 50) = 1.28 MPa.
For L/d = 1, the calculated Sommerfeld number is about 0.121.
Using the applicable Raimondi–Boyd/PSG chart, friction coefficient f ≈ 0.00644.
From the chart, hmin/c ≈ 0.4, hence hmin = 0.4 × 0.05 = 0.020 mm.
Surface speed v = πdN/60 = 3.901 m/s.
Power loss = fWv ≈ 80.4 W.
Total oil flow ≈ 0.403 L/min; using the stated heat-carrying assumption, temperature rise ≈ 7.9°C.
Final: f = 0.00644; power loss ≈ 80.4 W; hmin ≈ 0.020 mm; flow ≈ 0.403 L/min; ΔT ≈ 7.9°C.

8. Line Shaft with Two Pulleys – Q16(a)

Given: belt tension ratio = 3:1, limiting tight tension = 2.7 kN, shaft 40C8, Sut = 650 MPa, Syt = 380 MPa, keyed pulleys, ASME kb = 1.5, kt = 1.0. Bearing spans: 450, 450 and 250 mm. Pulley diameters: A = 250 mm, B = 450 mm.

At A: T1 = 2700 N, T2 = 900 N. Belt pull = 1800 N and torque T = (1800)(250/2) = 225000 Nmm.
At B, the same torque gives T3 = 1500 N and T4 = 500 N, so horizontal belt pull = 2000 N.
Vertical reactions: RC ≈ 2191 N and RD ≈ 1409 N. Horizontal reactions: RC ≈ 435 N and RD ≈ 1565 N.
At pulley A, resultant bending moment Mb ≈ 1.005 × 10⁶ Nmm, which is the critical section.
ASME allowable shear before keyway reduction = min(0.30Syt, 0.18Sut) = min(114,117) = 114 MPa. For the keyed shaft, use 25% reduction → 85.5 MPa.
Using ASME combined bending/torsion relation with kb = 1.5 and kt = 1.0 gives d ≈ 44.95 mm.
Adopt shaft diameter = 45 mm.

9. Socket/Cotter Joint – Q16(b)

Given: two rods of 50 mm diameter, cotter plate thickness = 15 mm, 40C8 steel, Syt = 380 MPa, compressive yield = 2 × tensile yield, shear yield = 50% tensile yield, FOS = 6.

Allowable tensile stress = 380/6 = 63.33 MPa.
Allowable compressive stress = 760/6 = 126.67 MPa.
Allowable shear stress = (0.5 × 380)/6 = 31.67 MPa.
Rod load P = (π/4)(50²)(63.33) = 124.35 kN.
Applying the socket-end failure checks gives theoretical dimensions approximately: inside socket diameter 60.45 mm, outside socket diameter 84.21 mm, collar diameter 130.44 mm, and proportions a = 28.04 mm, c = 30.20 mm.
Adopt: inside diameter = 65 mm; outside diameter = 85 mm; collar diameter = 135 mm; a = 30 mm; c = 35 mm.
